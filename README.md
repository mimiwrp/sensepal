# SensePal 🌟

SensePal is a web application designed to help people find and navigate sensory-friendly places in their area. Whether you're looking for quiet spaces, places with natural lighting, or sensory-accommodating venues, SensePal helps you discover comfortable spaces that meet your sensory needs.

## Features

- 🗺️ Interactive map interface using Google Maps API
- 🔍 Search for nearby sensory-friendly locations
- 📍 Real-time location-based recommendations
- ⭐ Detailed place information including ratings and reviews
- 🏷️ Quick filters for different sensory preferences
- 📱 Responsive design for both desktop and mobile use

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Google Maps API key

### Installation

1. Clone the repository
```bash
git clone [your-repo-url]
cd sensepal
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Create a `.env` file in the root directory and add your Google Maps API key:
```env
VITE_GOOGLE_MAPS_API_KEY=your_api_key_here
```

4. Start the development server
```bash
npm run dev
# or
yarn dev
```

## Tech Stack

- Google Maps JavaScript API
